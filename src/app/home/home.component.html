Regression and Classification Models for Apple Quality Dataset

Description: This project was designed to predict the quality of apples based on various physical and chemical features. We began by gathering data on apple size, weight, sweetness, crunchiness, juiciness, ripeness, and acidity. After cleaning and preprocessing the dataset, including transforming the quality ratings into binary labels, we used multiple regression and classification models to evaluate the apple quality. The models tested included Linear Regression, Decision Tree, Random Forest for regression tasks, and Logistic Regression, Decision Tree, and Random Forest for classification tasks. After rigorous evaluation using confusion matrices and ROC curves, the Random Forest models achieved high accuracy in predicting both quality and classification of apples, providing valuable insights into product grading and marketability. This project demonstrated the ability to work with machine learning models to make data-driven predictions that can help improve the agricultural industry.
Key Insights:
  • Random Forest performed best in regression with the lowest mean squared error (MSE).
  • In classification tasks, all models achieved an accuracy of 90%.
  • Feature importance analysis showed that size and ripeness were the most significant predictors of apple quality.
Tools/Technologies Used:
  • Python (scikit-learn, Pandas, Matplotlib)
  • Jupyter Notebooks
  • Random Forest, Logistic Regression, Decision Trees
  • Data Preprocessing and Exploratory Data Analysis (EDA)
